# Python Tasks Repository

Welcome to the Python Tasks Repository. This repository is dedicated to housing a collection of structured, professionally developed Python projects designed to demonstrate proficiency in various domains, ranging from web scraping to data processing and backend automation.

## Overview

The repository consists of multiple tasks that leverage a broad spectrum of Python libraries and tools. Each task is isolated within its own thoughtfully structured directory, ensuring modularity, maintainability, and clear separation of concerns.

### Key Technical Focus Areas:
- **Web Scraping & DOM Parsing**: Utilizing libraries like Playwright, BeautifulSoup, and LXML to bypass complex bot-detection systems and parse dynamically rendered content.
- **Data Engineering & Storage**: Managing structured schemas, implementing robust unique constraints, and efficiently interacting with SQL databases (SQLite/PostgreSQL) to store and query extracted data.
- **Reporting & Orchestration**: Building modular pipelines that analyze differences in datasets (e.g., price comparisons), generate daily automated CSV reports, and provide clean console logging.
- **Clean Architecture Principles**: Ensuring robust decoupling between data extraction, data storage, business logic (comparison), and presentation layers.

Navigate to the individual task directories (e.g., `task-1/`) for specific documentation, objectives, setup instructions, and execution mechanics.
